Data Storage ​

JoyMart provides two storage backends: YAML files (default, single server) and MySQL (recommended for cross-server). The storage mode is configured in the storage block of config.yml — see Configuration Files.

YAML (default, single server) ​

  • Player data: plugins/JoyMart/data/players/<uuid>.yml
  • High scores: plugins/JoyMart/data/scores/<gameId>.yml

MySQL (recommended for cross-server) ​

Enable mysql.enabled: true in config.yml and fill in the connection details. JoyMart automatically manages connections via a HikariCP connection pool; all BungeeCord sub-servers share the same high-score table and token data.

Data Migration ​

Migration commands

/gba migrate mysql imports existing YAML data into MySQL; /gba migrate file does the reverse.

The migration command requires the gamebox.admin.migrate permission — see Commands & Permissions.
