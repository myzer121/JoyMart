Per-Game Configuration ​

Each game's runtime parameters (icon, cost, GUI size, score scaling, rewards, game-specific settings, etc.) live in a dedicated plugins/JoyMart/games/<id>/config.yml file. On first server startup the plugin auto-copies the default config from inside the jar; afterwards admins can edit it by hand or through the in-game GUI (recommended). Either way, run /gba reload to hot-reload — no restart needed.

This page documents the game-specific options and a full example for each of the 15 games. For how each game plays see Game Modes; for how scores and rewards are calculated see Scoring & Events.

Auto-copy mechanism

The plugin creates a sub-directory named after each game id under plugins/JoyMart/games/ (e.g. 2048/, minesweeper/, monopoly/). If a config.yml is missing, the plugin copies the matching default file out of the jar; deleting the file regenerates the default on next startup. To toggle games or change their sub-commands see Configuration Files.

Common Fields ​

The fields below form the shared base structure of every game's config.yml. Not every field appears in every file — some games omit inapplicable ones (for example, versus games usually have no scorePerToken / trackHighScore); omitted fields fall back to their defaults.

FieldTypeDescription
icon.materialMaterialItem shown in the game selection GUI (Spigot 1.21 material name, e.g. PAPER)
costDecimalEconomy cost to start a game (0.0 = free)
guiSizeIntegerSize of the game inventory (must be a multiple of 9, range 9–54)
scorePerTokenIntegerBonus tokens = score ÷ scorePerToken (0 = no score-based token scaling)
moneyPerTokenDecimalBonus money = bonus tokens × moneyPerToken (0.0 = no money scaling, requires Vault)
trackHighScoreBooleanWhether scores are saved to the high-score table
rewards.win.tokensIntegerTokens awarded on a win
rewards.win.moneyDecimalMoney awarded on a win (requires Vault)
rewards.win.commandsListConsole commands run on a win (%player% replaced with the player name)
rewards.lose.tokensIntegerTokens awarded on a loss
rewards.lose.moneyDecimalMoney awarded on a loss (requires Vault)
Single-player vs. versus reward structure
  • Single-player / Lottery / Slot Machine: use the rewards.win and rewards.lose branches.
  • Versus games (Chess, Battleship, Connect 4, Tic-Tac-Toe, Rock-Paper-Scissors, Monopoly): use the rewards.winner / rewards.loser / rewards.draw branches; winner and loser may each carry their own commands.

Lottery and Slot Machine pay out from their own prizes pool, so their rewards block is just a placeholder (usually 0). See Scoring & Events for the full reward logic.

Material names target 1.21

icon.material must use Spigot 1.21 material enum names (e.g. BROWN_CONCRETE, END_PORTAL_FRAME). Some names differ on older servers — update them after upgrading.

2048 ​

The classic number-merging game: slide tiles on a 4×4 grid to combine equal numbers, aiming to build the 2048 tile. Merge score is converted to bonus tokens via scorePerToken.

Game-specific settingDefaultDescription
settings.gridSize4Grid edge length (4 = 4×4)
settings.targetTile2048Tile value required to win
yaml
icon:
  material: PAPER

cost: 0.0
guiSize: 45
scorePerToken: 100
moneyPerToken: 0.0
trackHighScore: true

settings:
  gridSize: 4
  targetTile: 2048

rewards:
  win:
    tokens: 10
    money: 5.0
    commands: []
  lose:
    tokens: 1
    money: 0.0

Minesweeper ​

Classic Minesweeper. guiSize must equal rows × cols and not exceed 54; cols is capped at 9 to fit the chest width. The default board is 6×9 = 54 cells with 10 mines.

Game-specific settingDefaultDescription
settings.rows6Number of rows (constrained by guiSize)
settings.cols9Number of columns (max 9)
settings.mines10Number of mines
yaml
icon:
  material: TNT

cost: 0.0
guiSize: 54
scorePerToken: 100000
moneyPerToken: 0.0
trackHighScore: true

settings:
  rows: 6
  cols: 9
  mines: 10

rewards:
  win:
    tokens: 15
    money: 10.0
    commands: []
  lose:
    tokens: 1
    money: 0.0

Grid and inventory size are linked

After changing rows / cols, set guiSize to rows × cols (and keep it a multiple of 9) or the cells won't fill the inventory.

Lottery ​

A numeric lottery: players pick pickCount numbers from a pool of poolSize, then the game draws pickCount winning numbers. The match count selects the prize tier (prizes[matches]).

Tokens only

The lottery only awards tokens — no items or money. Even if you fill in money / commands on a prize, they have no effect.

Game-specific settingDefaultDescription
settings.poolSize16Size of the number pool
settings.pickCount4Numbers picked by the player / drawn by the game

Prize tier format ​

prizes is a list indexed by match count (subscript 0..pickCount); weight is unused for the lottery (tiers are selected by matches, not weighted random). material / name are only used to display the tier in the "Edit Prizes" GUI.

Editing via GUI is easier

Lottery prize tiers can be added, removed, and tweaked in-game via the "Edit Prizes" button (requires gamebox.admin.games); changes are written back to this file. The shared prize-pool field reference is in Configuration Files.

Default prize names are in Chinese

The shipped default name strings are in Chinese (e.g. &6头奖 (4 中全中!)) with & color codes. They are pure display labels — feel free to translate or rewrite them; only tokens affects the actual payout.

Slot Machine ​

A classic slot machine: each spin costs spinCostTokens tokens and the three reels stop on random symbols. The outcome is a weighted-random pick from the prizes list (higher weight = more likely). material is also used as the symbol shown on the center reel.

Prize pool format ​

Each prizes entry can award tokens, money (requires Vault), and console commands (%player% replaced with the player name) at once. This format is shared with the Lottery — see Configuration Files.

DIAMOND&b大奖2300.0give %player% diamond 1
NETHER_STAR&6超级大奖!1150100.0give %player% nether_star 1

Snake ​

Steer a snake around the grid eating food; the snake speeds up as it grows. startIntervalTicks is the initial move interval; each food eaten shaves off speedupTicks ticks, down to a floor of minIntervalTicks.

Game-specific settingDefaultDescription
settings.startIntervalTicks20Initial move interval (ticks, 20 = 1 second)
settings.minIntervalTicks6Minimum move interval after speed-up (lower = faster)
settings.speedupTicks1Ticks removed per food eaten

scorePerToken: 50
moneyPerToken: 0.0

    money: 0.0

Dino Run ​

A side-scrolling runner: the dino runs in place while cacti scroll in from the right — click jump to clear them. scrollIntervalTicks controls world scroll speed; minObstacleGap / maxObstacleGap bound the spacing between consecutive cacti (the gap shrinks as your score rises, ramping up difficulty).

Game-specific settingDefaultDescription
settings.scrollIntervalTicks6World scroll interval (ticks, lower = faster)
settings.minObstacleGap4Minimum gap between cacti (scroll steps)
settings.maxObstacleGap9Maximum gap between cacti (scroll steps)

Chess ​

A 6×6 Los Alamos chess variant (no bishops), playable against another player or a simple AI. Pieces per side: 1 King, 1 Queen, 2 Rooks, 2 Knights, 6 Pawns. The 6×6 board is used because a Bukkit inventory caps at 54 slots — Los Alamos is the closest playable international-chess-like variant that fits. Win/lose/draw use rewards.winner / rewards.loser / rewards.draw.

yaml
icon:
  material: GOLD_BLOCK

cost: 0.0
guiSize: 54
scorePerToken: 0
moneyPerToken: 0.0
trackHighScore: true

rewards:
  winner:
    tokens: 15
    money: 10.0
    commands: []
  loser:
    tokens: 1
    money: 0.0
    commands: []
  draw:
    tokens: 2
    money: 0.0

Battleship ​

    tokens: 2

About cost

Battleship starts via the two-player invite flow and does not charge cost; the value is only consulted for single-player affordability checks (there is no single-player flow here). It defaults to 0.0.

Monopoly ​

A GUI recreation of classic Monopoly, supporting 2–3 players or 1 human + AI. startMoney is each player's starting cash, passGoBonus the bonus collected when passing GO, and jailFee the fee to leave jail. 17 properties are laid out around a 26-space board; prices and rents can be edited here or via the in-game settings editor GUI.

Game-specific settingDefaultDescription
settings.startMoney2000Starting cash per player
settings.passGoBonus200Bonus collected when passing GO
settings.jailFee50Fee paid to leave jail
