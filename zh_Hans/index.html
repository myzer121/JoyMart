JoyMart小游戏大厅插件

为 Spigot / Paper 1.21 打造的全 GUI 我的世界小游戏大厅插件。15 款游戏全部内置，丢进 plugins/ 即开箱即玩。

🎮

15 款内置游戏

单人、双人、多人游戏全覆盖，包括 2048、扫雷、贪吃蛇、国际象棋、大富翁等，全部内置在主 jar 中。

查看游戏

🖱️

纯 GUI 操作

通过箱子界面选择游戏，玩家无需记忆任何指令，点击即玩。

🪙

代币系统

自带 JoyMart 代币，可选挂钩 Vault 经济。支持代币商店、高分榜、跨服同步。

🤖

AI 对战

双人游戏支持邀请好友或直接对战 AI，无需等待对手。

💾

双存储模式

YAML 文件（默认）或 MySQL（HikariCP 连接池，支持 BungeeCord 跨服）。

🔌

公开 API

通过 GameBoxAPI 或 Bukkit ServicesManager 供其他插件调用，支持自定义事件。
